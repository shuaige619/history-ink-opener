# 片头进入正文：交接契约

片头的末镜要在**意义、画面和声音**上交给正文。分镜开始前，先从现有正文读取或明确待定以下内容：

| 锚点 | 必须写出的实际值 |
| --- | --- |
| 正文文字 | 片头区间实际口播原句与接点后首句／段，以及标题／人物关系／问题是否已交代 |
| 音轨 | 开头音频文件、样本率、首句时间；没有真实音轨时标估算，不伪造时间戳 |
| 字幕 | 首条字幕及原 cue 时间；实际有片名贴字时才记其撤场时间 |
| 正文首画面 | 人物/物件/地点、构图方向、来源与有效状态 |
| 片头末态 | 最后一镜的人物朝向、动作/物件位置、画面明暗及准确片名状态 |
| 接法 | 由人物视线、同一动作/物件、墨迹方向或场所关系带出的一个明确剪辑点 |

正文已存在时，优先让片头最后的可读动作与正文首画面形成空间或语义承接；镜头末尾预留的停顿由实际声音和文字决定。片头若已经读出或展示了标题，接点后不能再次重放同一段标题画面和开场口播。模型生成的人声、伪字或未经听审的音乐不能覆盖已冻结的旁白和字幕。

按[片头口播与画面联动](narration-picture-design.md)连读动画末句与正文接句；新拟段落并入主稿，改词后先重核当前文本及受影响的音轨／字幕绑定。未配音时给出文字方案与估时，真实音轨存在时按原cue选择动画覆盖区间，不在原第0帧前另插一段新旁白。

`title_sequence` 的时代意象与人物肖像可以处于象征空间，末镜通过轮廓、视线、墨色或主题交给正文，地点不必与正文同一现场。接片时仍核实际出现人物的年龄、脸、须发和衣冠；有跨时代设计须明确范围和依据，不能把象征合成误记为一次真实会面。

在 `AI写作` 工作区选择 `ink_dynamic` 时不制作片名标题卡，也不把口播朗读的正式标题再写到动画画面上；仅按项目规范保留原字幕及必要的人物姓名—当时身份题签。因此片名贴字和其撤场时间在该模式记为“不适用”，不能为了填交接表补一张标题卡。

产出一段**跨切点**的预览，至少看见片头最后动作和正文首个有效画面，听见接点两侧的声音；检查无黑帧、闪帧、突变、重复镜头、漏首句、音量骤跳或字幕延迟。最终记录片头末帧、正文首帧、两侧源文件及 SHA、实际时间轴帧号和检查范围。仅有片头 MP4 或理论分镜时，状态是 `opener_ready_body_pending`，不能称“进入正文”。

若正文只是一份未配音的文稿，片头以一个可接的末帧和声音余量收束，交 `body_anchor_pending`；不要用虚构朗读时间把片头剪到所谓正文第 0 秒。
