# 人物设定到生成提示词

片头有人物时读取本文件。目标是让故事中的关键人物成为图片和视频生成请求的明确主体，外貌、状态与镜头关系均可执行。只选本期确有作用的出场人物，不为了填模板增加角色或新生图。

## 1. 从故事提炼人物的可见特征

每位主要人物记录以下信息，已有角色卡可直接补齐：

| 项目 | 设计内容 |
|---|---|
| 身份与阶段 | 角色ID、姓名、本期当时身份、所选人生阶段；正文／来源ID与参考依据 |
| 外貌与衣冠 | 脸型、眉眼、须发、发式／冠帽、体态、衣袍形制／材质／颜色；区分现有参考、有据事实与美术设计 |
| 人物特征 | 从本期有据选择或处境提炼主导特征，不凭知名标签代替正文判断 |
| 可见表达 | 特征怎样通过目光、嘴部、肩颈、姿态、轮廓及构图读出；片头肖像可以稳定不演动作 |
| 跨镜固定项 | 同一阶段需保持的脸、须发、冠帽、衣冠和关键物件；实际身份参考及SHA |
| 出场与交接 | 所在镜头、景别／位置、与前后人物及宏观背景的关系、遮挡载体与正文接点 |

例如，设计上把“克制”转成闭唇、肩颈稳定、目光投向画外；把“掌兵者的压迫感”转成略低机位、稳定正侧脸、深墨衣袍轮廓及远景旗阵。可见表达属于本次美术选择，不反推为人物真实相貌、性格史证或实际战役。

## 2. 冻结人物基础描述

依据导演G模式的连续性契约写一条正向基础描述，供同一阶段的各镜复用。包含能辨认人物的脸／须发／冠帽、体态与衣冠锚；姓名本身不能代替这些信息。把具体镜头的表情、机位和景别放在镜头描述中，避免基础描述随镜头被重写。

历史任务的证据约束优先：缺精确年龄时记录所选年龄阶段或明确的美术假设，不把上游模板的数字年龄或独特疤痕要求变成史实。已有造型参考优先，不自动增添痣、伤疤等标记，不以某位影视演员的脸替代本期人物。同一人跨明显年龄／身份阶段时建立对应造型版本并注明变化，不能让模型自行老化或换装。

图片与视频需要不同语言时一次确定同义版本并沿用；不要逐镜临时翻译造成造型变化。基础文字与参考绑定一起约束角色，但都不能被称为保证锁脸。

## 3. 写出图片 prompt

导演E模式的每张有人的关键帧必须落到具体生成文字：

```text
人物基础描述
＋本镜可见状态（目光、嘴部、肩颈、姿态；需要时写简单动作起态）
＋景别、角度、画面位置、人物与背景的尺度关系
＋本期时代背景及前中远景层次
＋墨色、纸色、光线、飞白和湿墨处理
＋本镜转场载体的形状／位置及人脸可见区
＋本镜实际需要的排除项
```

这只是写作顺序；提交前展开成完整 prompt，不发送上述占位文字。工作台文生图时写实际外貌，不发送内部角色ID或H3的参考标签；仅当接口确实支持图像条件时绑定对应角色／关键帧原件并记录实际顺序。没有上传图片的请求如实标为文字设计，种子一致不等于身份参考。

人物单独设定图只在没有适用身份依据、需要额外造型控制且本次范围允许时准备；可直接以完整片头关键帧同时承担造型和构图参考，不强加每人三视图或额外付费肖像。人物的宏观背景不必演某一幕剧情，叠映须明确是片头美术层，避免巨人或未经证实的同场会面。

## 4. 将人物编入视频 prompt

依据最终实际关键帧编译，不能只把图片 prompt 拼成视频故事梗概。

- **H3 Ref2VA**：每位实际出现的重要人物有独立 `<Subject N>`，定义其身份／可见外貌及真正提供这些特征的参考资产。背景、笔墨和转场载体可另定义主体；不把人物揉成“古装群像”。`retention_analysis`列其出场镜头与应保留项；`detailed_description`在首次清楚出场时写可见特征、位置、目光／姿态或简单动作，并在后续沿用同一标签。标签编号由实际定义顺序决定，不固定某人永远是Subject 1。
- **T2VA／I2VA／FL2VA／L2VA**：按官方base指南写人物的实际可见特征、状态与时序；只描述模式真实提供的首／尾帧，不自行加入未上传的Picture或Subject参考标签。
- **每个出场镜头**：明确此人是谁、占画面哪里、眼睛与身体朝哪边、如何从起态到末态、镜头如何运动、哪一层遮住／揭开下一镜。稳定肖像可以不演动作，让镜头、云墨或衣袍边缘承担转换；不靠变脸／换须发转场。
- **不可见部分**：远景背影写冠帽、衣袍、轮廓等实际可辨项，不能要求观众看清微小人脸。人物被暂时遮住时交代遮挡与再显现，不凭“人物没有变化”断言实际保留成功。

H3字段、参考标签与保留度标记以官方 `h3-prompt-writing` 指南为准，本文件只补人物如何进入这些字段。准确姓名题签仍在后期排版，不能拿题签替代人物造型定义。

## 5. 设计交付与检查

在本期既有导演方案／提示词记录中给出人物清单、基础描述、特征→可见表达、逐镜图片 prompt、视频人物定义与逐镜描述、角色ID→镜头→实际参考→H3标签映射；不强制另建一套文件。仅设计时参考可标待生成，视频字段不伪称已有图片。

提交前核人物描述确实进入实际请求；同一阶段固定项不互相冲突，角色参考与风格参考作用分明，人物和背景分别可读。生成后按项目现行图片通道规则及视频完整采用区间检查，不以文字中“完全保留”、同一随机种子或用户接受前例代替实际结果。只修本次失败或受影响的角色镜头，沿有效额度执行。
