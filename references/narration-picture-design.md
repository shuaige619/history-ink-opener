# 片头口播与画面联动

适用于有历史旁白的片头设计及正文接片。先明确开头要让听众理解什么，再让口播、人物与宏观历史画面共同表达。不强迫每句话复演一个故事场景；云墨、旌旗和肖像轮廓可以承担视觉转换，旁白继续推进人物处境与问题。

## 1. 选择本次文字处理方式

| 方式 | 如何执行 | 交付状态 |
|---|---|---|
| `reuse_locked`：已有有效稿件／音轨 | 读取实际开场原句、来源和当前cue，由原语义设计镜头。认为开头不适合时先列具体建议，不直接改已锁文字或声音 | 原文复用；有音轨才标真实时间 |
| `draft_for_sample`：独立有声样片、暂无可用正文 | 按本期已核材料拟开场口播与拟接正文句，标为试片草案；来源或正式标题未定时保留待核 | 草案／估时；不称完整口播稿已验收 |
| `revise_master`：新稿或本次明确修订开头 | 作为整期主稿开头写入并连读后续正文，执行项目文字审校、独立评审和验收，再更新受影响的音轨／字幕及镜头绑定 | 当前主稿通过后再冻结媒体时钟 |

用户只要画面或明确无声效果样片时，记录相应语义／口播依据，不因此新增配音任务。只优化流程时保存指引，不自动改某一作品。设计提案不冒称正式文稿通过，不把重新配音或出视频强加到设计任务中。

## 2. 给作者的口播设计指令

以下是作者brief，不直接交给图片或视频模型：

```text
根据本期已读正文与史料设计开场口播。
本期正式标题／暂定标题与研究范围：
人物当前身份、关系、压力与有据的关键变化：
本期追查的问题及后续兑现位置：
可用事实、来源ID和尚待核事项：
片头视觉形式、人物特征及时代意象：
现有开场原句、下一句／段及音轨是否已锁：
本次文字方式、动画目标时长和可调整范围：
按项目开场要求拟口播或复用原句，逐句标信息功能和事实来源，
给出动画末句怎样接正文。文字估时与实际音轨时间分开。
```

尽快讲清谁／什么事件、此时面对什么局面、本期要追查哪项变化。使用具体关系、压力、选择或后果，不以“历史长河”“风云变幻”“命运齿轮”等空泛句填时长，不堆年代、官职和人名。人物评价与来源归属明确，艺术肖像不充当性格或史实证据。

在 `AI写作` 工作区，实际新写／实质改稿先读《历史口播生成规范.md》、`workflow/voiceover-policy.json`、`workflow/口播测试员评测指令.md`；人物传记另读专门规范。开头默认用本题身份／具体经历与有据钩子直接起讲，不单独朗读发布标题，省略栏目招呼；听众理解、评价归属、首件行动与兑现仍须审查，场景后不重复报题。首帧从动画镜头直接设计，独立关键帧只作模型参考，不先制作封面再动画化。片头口播在整期主稿内连续进入正文，全文按原初复评及check/finalize办理；不另设片头分数，不以短段审阅替代整稿评审。

片头蒙太奇可保持象征画面，口播本题入口仍须具体。叙事顺序由本期选择，不强制每期“时代背景→人物→提问”三句齐备，不把试片秒数当口播配额。完整开头可跨动画末尾继续进入正文，不必把所有开场功能塞入十秒。

## 3. 编排口播—画面对应表

保存在既有导演方案或开场计划内即可：

| 字段 | 内容 |
|---|---|
| 原句／cue及版本 | 实际朗读原句、正文定位／SHA；音轨存在时关联真实cue与音频版本 |
| 信息功能与来源 | 报题、人物身份、时代压力、具体变化、问题或进入正文等本题功能；史实的来源ID |
| 人物和背景 | 关注谁、其可见目光／姿态与造型版本；背景表达何种时代处境，象征合成注明 |
| 镜头与转场 | 镜头ID、起末态、前中远景层次、遮挡显现载体与计划转换位置 |
| 时间依据 | 文字估时或真实音轨；实际停连与帧／样本位置；未听辨的段内切点待核 |
| 正文接句 | 动画末句与下一句／段的实际原文；人物局面、选择或问题怎样继续推进 |

一段口播可以跨镜，一镜也可承接多句；切镜跟随语义、声音节拍和视觉需要，不按字数平均切分，不固定一句一镜。人物姓名可在旁白介绍前短暂显现，必要关系应及时讲清；题签不替口播交代因果。旁白不必逐项讲“墨迹展开”“旗帜飘过”，除非物件本身是故事事实。

## 4. 从文字估时到真实音轨

未配音时按项目语速口径、标点与必要停顿估时，标区间与依据，不伪造逐句小数时间或实际试听。口播与分镜预案可以迭代，媒体请求须绑定当前实际采用的文字与参考。

新稿先完成当前文字验收，再按授权准备音轨；声音就绪后按实际停连／cue回定镜头、遮挡与正文接点。已有音轨时优先按原时钟配画面。目标动画长度放不下时记录差异，在已准许范围内简化必要信息或调整镜头／覆盖区间，也可让同一旁白跨动画与正文连续说完；不靠加速、漏词、额外静音或整轨后移解决。

实际改词须按主稿修订门禁重验受影响版本，不能后期单换第一段声音而继续引用旧稿评分。仅时间变化、文字未变时沿原复用规则。修改主稿不自动获得新TTS、图片、视频或重试额度。

## 5. 正文与声音交接

连读动画末句与正文下一句，删去重复招呼、报题、同一悬念或无收益的“接下来我们就讲”；宏观背景在画面中收束，正文继续有据过程。

本工作区旁白／字幕从原第0帧开始，片头替换现有开场画面区间，不额外插新配音再从头播放旧开场。H3只生成画面、后期用项目旁白时按实际请求写声音安排；无声请求继续使用官方适用的N/A或无声描述，不虚构上传旁白参考，不让模型随意生成口播覆盖当前音轨。

检查原句与字幕一致、实际声音与画面人物／时代含义吻合、转场不吞字、末句与正文不重复、声音连续及尾部完整。文本对应表不等于真实视听通过；正文缺失仍待接片。分别记录文字是原文复用／草案／当前验收稿，时间是估算／实测，声音是未生成／已有／已核。
